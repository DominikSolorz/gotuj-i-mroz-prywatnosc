# Gotuj i Mroź

Gra o gotowaniu i mrożeniu (HTML5 + Capacitor, Android).

- `gotuj-i-mroz/` – kod gry, projekt Android, materiały do Google Play
- `index.html` w katalogu głównym – polityka prywatności (GitHub Pages)

Polityka prywatności: https://dominiksolorz.github.io/gotuj-i-mroz-prywatnosc/

Budowa: w folderze `gotuj-i-mroz` uruchom `npm install`, `npx cap sync android` i zbuduj w Android Studio.
Klucz podpisu (release-keys) NIE jest w repozytorium i nie powinien być publiczny.
